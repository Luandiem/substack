# SEO GUIDE

Version: 1.0

---

# Purpose

This guide defines the SEO standards for all content published by the Luận Điểm project.

Its purpose is to improve discoverability, readability, and long-term organic traffic while maintaining high editorial quality.

---

# SEO Principles

- Write for people first, search engines second.
- Prioritize accuracy over keyword density.
- Use clear and descriptive titles.
- Focus on search intent.
- Avoid clickbait.
- Build evergreen content whenever possible.

---

# Keyword Strategy

## Primary Keyword

One primary keyword per article.

## Secondary Keywords

Support the primary keyword naturally.

## Long-tail Keywords

Target specific search queries with lower competition.

---

# Search Intent

Identify the user's intent before writing.

- Informational
- Educational
- Comparative
- Navigational

---

# Title Standards

- Clear and descriptive
- Include the primary keyword
- 50–60 characters when possible
- Avoid misleading titles

---

# Meta Description

- 120–160 characters
- Summarize the article
- Include the primary keyword naturally
- Encourage clicks without exaggeration

---

# URL Slug

- Short
- Descriptive
- Lowercase
- Hyphen-separated
- Remove unnecessary words

Example:

business-model-vietcombank

---

# Heading Structure

Use a logical hierarchy.

H1 → Title

H2 → Main Sections

H3 → Subsections

Avoid skipping heading levels.

---

# Internal Linking

Link to:

- Related company analyses
- Industry reports
- Educational articles
- Research notes

---

# External Linking

Only reference authoritative sources.

Examples:

- Company Website
- Annual Report
- Financial Statements
- Government Sources

---

# Image SEO

Every image should include:

- Descriptive filename
- Alt text
- Caption (if appropriate)

---

# Content Quality

Articles should:

- Answer the search intent.
- Be factually accurate.
- Use original analysis.
- Be easy to read.
- Provide actionable insights.

---

---

# SEO Checklist

Before publishing, verify:

- Primary keyword included
- SEO title completed
- Meta description completed
- URL slug optimized
- Proper heading structure
- Internal links added
- External references verified
- Images optimized
- Grammar checked

---

# Golden Rules

Write for readers.

Support every claim with evidence.

Avoid keyword stuffing.

Create evergreen value.

Consistency beats shortcuts.
